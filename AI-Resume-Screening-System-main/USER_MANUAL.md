# AI Resume Screening System - User Manual

## 1. Introduction

The AI Resume Screening System helps users compare a candidate resume with a job description. The system analyzes the resume, calculates a match score, shows matched and missing skills, generates a match report, and displays algorithm performance graphs.

The system has two login types:

- User
- Admin

## 2. Starting the System

Open the project folder and run:

```powershell
python -m flask --app app run --host 127.0.0.1 --port 5000
```

After the server starts, open this link in a browser:

```text
http://127.0.0.1:5000/login
```

## 3. User Module

### 3.1 User Registration

1. Open the login page.
2. Click **Create an account**.
3. Enter:
   - Full name
   - Email
   - Username
   - Password
4. Click **Register**.
5. After successful registration, log in using the created username and password.

### 3.2 User Login

1. Open the login page.
2. Enter the registered username and password.
3. Click **Login**.
4. The user dashboard will open.

### 3.3 Update Profile

1. Log in as a user.
2. Click **Profile** from the top menu.
3. Update details such as:
   - Full name
   - Email
   - Phone
   - Skills
4. Click **Update Profile**.

### 3.4 AI Resume Screening & Job Matching

1. Log in as a user.
2. Click **Screen Resume**.
3. Enter the job title.
4. Upload a resume in PDF or DOCX format.
5. Paste the job description.
6. Click **Analyze Score**.

The system will analyze the resume and open a new match report page.

### 3.5 View Match Result

The match report page shows:

- Match score
- Match category
- Candidate details
- Resume file name
- Matched skills
- Missing skills
- Recommendation

Match categories are:

- Great Match
- Good Match
- Average Match
- Poor Match

### 3.6 Generate Match Report

After screening a resume, the system automatically generates and saves a report.

To print the report:

1. Open the report.
2. Click **Print Report**.
3. Use the browser print option to print or save as PDF.

### 3.7 View User Reports

1. Log in as a user.
2. Click **Reports**.
3. The user can view only their own generated reports.
4. Click **View** to open a full report.

### 3.8 Algorithm Performance Graph

1. Log in as a user.
2. Click **Performance**.
3. The page shows:
   - Total reports generated by the user
   - Average match score
   - Match category distribution graph

## 4. Admin Module

### 4.1 Admin Login

Use the default admin credentials:

```text
Username: admin
Password: admin
```

After login, the admin dashboard will open.

### 4.2 Manage Users

1. Log in as admin.
2. Click **Manage Users**.
3. The admin can view all registered users.

### 4.3 Add User

1. Open **Manage Users**.
2. Click **Add User**.
3. Enter:
   - Username
   - Password
   - Role
   - Full name
   - Email
   - Phone
   - Skills
4. Click **Save User**.

### 4.4 Update User

1. Open **Manage Users**.
2. Click **Edit** beside a user.
3. Update the required details.
4. To keep the old password, leave the password field blank.
5. Click **Save User**.

### 4.5 Delete User

1. Open **Manage Users**.
2. Click **Delete** beside a user.
3. The selected user and their generated reports will be removed.

The admin cannot delete their own currently logged-in admin account.

### 4.6 Admin Resume Screening

The admin can also perform AI Resume Screening & Job Matching.

1. Log in as admin.
2. Click **Screen Resume**.
3. Upload a resume and enter the job description.
4. Click **Analyze Score**.
5. The system generates a match report.

### 4.7 View All Generated Reports

1. Log in as admin.
2. Click **Reports**.
3. The admin can view all reports generated by all users.
4. Click **View** to open any report.

### 4.8 Admin Algorithm Performance Graph

1. Log in as admin.
2. Click **Performance**.
3. The admin can see performance data based on all generated reports in the system.

The graph displays:

- Total generated reports
- Average match score
- Number of Great, Good, Average, and Poor matches

## 5. Match Score Explanation

The system compares skills found in the resume with skills required in the job description.

Example:

If the job description requires:

```text
python, flask, sql, machine learning
```

And the resume contains:

```text
python, flask, sql
```

The system calculates the match percentage based on the matched skills.

## 6. Supported Resume Formats

The system supports:

- PDF
- DOCX

Other file formats are not supported.

## 7. Common Problems and Solutions

### Invalid Login

Check that the username and password are correct.

### Resume Not Uploading

Make sure the resume is in PDF or DOCX format.

### Low Match Score

The resume may not contain the required skills from the job description.

### Performance Graph Is Empty

Generate at least one match report first.

## 8. Logout

To exit the system:

1. Click **Logout** from the top menu.
2. The system returns to the login page.
